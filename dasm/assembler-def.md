# 汇编器所指定的伪代码
| 伪代码名称 | 功能 |
|---|---|
| SECTION TEXT | 以下内容为代码段（这是默认的，所以不强制要求） |
| SECTION DATA | 以下内容为数据段 |
| DB <ADDR>, <DATA> | 在当前段的固定地址定义字节数据 |
| DW <ADDR>, <DATA> | 定义WORD数据 |
| DD <ADDR>, <DATA> | 定义DWORD |
| DQ <ADDR>, <DATA> | 定义64位数据 |
| <LABEL>: | 定义标号 |
| ORG <ADDR> | 计算本段标号时，从ADDR偏移开始 |
| %define <NAME> <MACRO> | 定义宏 |
| %include <FILENAME> | 包含其它文件 |
| $ | 在解析时被展开为当前的地址 |
| RESB <NUM> | 保留NUM个字节的数据 |
| EXTERN <LABEL> | 声明一个外部标号（仅在生成 ELF 时产生未定义符号/重定位） |

## 立即数规定：

10进制立即数可以直接表示，例如12844、19255、131072等。

16进制立即数，用0x或0X作为前缀。例如0x10000、0X12A、0x0BADBEEF、0x0badbeef等。大小写任意。

2进制立即数，用b或B作为后缀。例如00001101B、10000100b等。

立即数可以用“_”作为不影响可读性的分隔符。例如：131_072等价于13_1072等价于131072。0x0000008f等价于0x0000_008f。0000_0010B等价于00000010B。

标号在编译时会作为立即数使用。

## 命令的格式：

一条命令的通用格式：

`<命令>[可能的NZ后缀] [可能的尺寸] [<目标操作数>[, <源操作数>]]`

或

`<命令>[可能的NZ后缀] [<目标操作数>[, [可能的尺寸] <源操作数>]]`

这两者在双操作数的命令中是等价的。

例如：`INC D2`、`PUSH DWORD X`、`XORNZ BYTE D1, D1`、`NOP`是合法的。

`LETNZ WORD A, 0x1234`等价于`LETNZ A, WORD 0x1234`。

寄存器、命令（或者伪代码）应该是大小写不敏感的。例如`LETNZ WORD A, 0x1234`等价于`letnz word a, 0x1234`。

## 立即字符串

一条立即字符串（或者立即字符），应当以`'`开头，`'`结尾；或者以`"`开头，`"`结尾。不能混用。

立即字符串应当被展开为一串16进制的字节。

例如：`'0'`应当被展开为立即数`0x30`。`"0123"`应当被展开为`0x30, 0x31, 0x32, 0x33`。

## 注释

单行注释应当以`;`开头，这一行的后续内容被忽略。多行注释应当以`/*`开头，`*/`结尾。中间的内容被忽略。

例如：

```
/* 下面的代码用于演示赋值功能。
   它们只是演示目的。作者是Hangco. */
let a, word 0x0200			; 将A寄存器赋值为0x0200。别忘了这里的word不能省略。
zero b						; 清空B寄存器

```
